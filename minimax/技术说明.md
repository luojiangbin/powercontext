# 技术说明（一页）

## 模块结构

```
app/rules.py            业务函数（待修复）
tests/test_rules.py     功能 + 回归测试
spec.md                 规格
sdd/seekdb_store.py     seekdb 资料存取与检索
sdd/powercontext_state.py  PowerContext 任务状态读写
sdd/minimax_agent.py    MiniMax 代码修改
sdd/context.py          上下文组装
run.py                  CLI（init / run / status）
```

## 上下文选择方式

1. 按任务关键词在 seekdb 的 `docs` 表做 `LIKE` 检索，取规格/代码/测试条目
2. 读取本地最新 `spec.md`、`app/rules.py`、`tests/test_rules.py`
3. 从 PowerContext 读取任务进度（`/v1/context/prepare`）
4. 三者拼接为一段上下文，交给 MiniMax

## 技术分工

| 技术 | 承担的作用 |
|---|---|
| MiniMax | 根据上下文生成修复后的 `app/rules.py` |
| seekdb | 存储规格/代码/测试，查询结果进入上下文 |
| PowerContext | 保存任务进度与验证结果，重启后可读回 |
