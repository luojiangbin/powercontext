# 技术使用记录

> 以下记录由 `python run.py run` 在干净环境执行时生成，用于核对三项技术的实际参与。

## MiniMax 开发记录

- 调用模型：见环境变量 `MINIMAX_MODEL`（默认 `MiniMax-M2`）
- 提供的上下文：`logs/context.txt`（规格 + 代码 + 测试 + seekdb 检索 + PowerContext 状态）
- 模型输出：`logs/minimax_output.txt`（修复后的 `app/rules.py` 全文）
- 结果：`logs/run.log` 中记录改前/改后测试 exit code

## 数据库查询记录

- 数据库：seekdb（`sdd` 库 `docs` 表，存规格/代码/测试）
- 检索：`sdd/seekdb_store.py::query()`，按任务关键词 `LIKE` 查询
- 记录：`logs/run.log` 中的「seekdb 检索记录」段

## PowerContext 状态写入与复用记录

- 写入：`sdd/powercontext_state.py::write_state()` → `POST /v1/memory/remember`
- 读回：`read_state()` → `POST /v1/atomic-memory/list`（按 kind 取最新）
- 复用验证：`python run.py status` 在服务重启后仍能输出任务进度

## 如何核对

```bash
python run.py init
MINIMAX_API_KEY=... python run.py run
python run.py status          # 模拟重启后读状态
cat logs/context.txt          # MiniMax 收到的上下文
cat logs/minimax_output.txt   # MiniMax 输出
cat logs/run.log              # 改前/改后测试结果 + seekdb 记录
cat logs/change.diff          # 代码差异
```
