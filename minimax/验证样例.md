# 验证样例

## 任务描述

修复业务函数 `is_adult` 的年龄边界：当前实现 `age > 18`，导致 **18 周岁被误判为未成年人**。

- **要改什么**：`app/rules.py` 中 `is_adult` 的判断条件
- **哪些原有行为必须保持**：
  - 17 岁仍判定为"非成年人"
  - 负数年龄仍判定为"非成年人"

## 有效规格（spec.md）

```
## R1 年龄判定
- 年满 18 周岁（含 18）为成年人。
- 18 周岁以下为未成年人。
- 负数年龄视为非法输入，应判定为"非成年人"。
```

## 初始数据

- `app/rules.py`：`return age > 18`（含 bug）
- `tests/test_rules.py`：3 个测试（1 个目标功能 + 2 个回归）

## 操作步骤

1. `python run.py init`
2. `MINIMAX_API_KEY=... python run.py run`
3. `python run.py status`（模拟重启后读状态）

## 预期结果

| 步骤 | 结果 |
|---|---|
| `run` 前 `pytest` | `test_adult_is_recognized` 失败（exit ≠ 0） |
| `run` 后 `pytest` | 3 个测试全部通过（exit = 0） |
| `status` | 输出含"已完成 / 改前 exit / 改后 exit / 待办" |
| `logs/change.diff` | 显示 `age > 18` → `age >= 18` |

## 规格更新验证

把 `spec.md` 中"年满 18"改成"年满 21"，重跑 `init` + `run`，`status`/上下文应使用新规格（本样例默认不演示，仅说明能力）。

## 重置方法

```bash
rm -rf snapshots logs
# seekdb 资料由 init 重建；PowerContext 作用域按 idempotency_key 复用
python run.py init
```
