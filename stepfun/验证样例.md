# 验证样例与复现步骤

## 环境

- Windows 10/11 + WSL2（seekdb 运行处）或任意可连 seekdb 的主机
- Node.js 20+、Chrome / Edge 最新版

## 步骤

1. 启动 seekdb（端口 2881）：

```bash
seekdb --nodaemon --base-dir=/var/lib/seekdb2 --port=2881
```

2. 启动后端：

```bash
cd server && npm install && node server.mjs
```

3. 浏览器打开 `http://127.0.0.1:8600`

## 样例：导入与检索

1. 会话填 `demo`
2. 语料框输入（每行 `标题|||正文`）：

```
机器学习入门|||机器学习是人工智能的核心，包括监督学习与无监督学习
深度学习基础|||深度学习使用多层神经网络自动提取特征
数据库事务|||事务的 ACID 属性与隔离级别，MVCC 实现多版本并发控制
```

3. 点「导入并向量化」→ 状态显示 `✅ 已导入 3 篇`（含 seekdb 写入与索引刷新毫秒数）
4. 查询框输入 `机器学习 神经网络` → 点「混合检索」
5. 预期：结果第 1 条为「机器学习入门」（关键词分 > 0、语义分 > 0，RRF 融合分最高），界面徽章显示当前推理后端（WebGPU 或 WASM+降级原因）

## 验证降级路径

- 打开 `http://127.0.0.1:8600/?force=wasm` → 徽章显示 WASM，流程仍可用
- 打开 `?dtype=fp32` → 加载 fp32 基线，流程可用

## 验证质量

- `http://127.0.0.1:8600/eval.html?dtype=q8` → 输出 Recall@5 / nDCG@5 JSON
- `http://127.0.0.1:8600/eval.html?dtype=fp32` → 同口径对比

## 验证会话与增量

- 会话改 `demo2` 重新导入 → 检索 `demo2` 只命中新数据
- 对同一会话连续两次导入 → 第二次写入后立即可检索（索引刷新确认）

## 数据生成

评测与样例语料可由 `scripts/gen_corpus.py` 生成（纯文本，无需外网）。
