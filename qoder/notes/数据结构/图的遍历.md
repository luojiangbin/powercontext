# 图的遍历

## DFS 与 BFS 的取舍

DFS 用栈（递归或显式栈），适合判断连通性、找环、拓扑排序、求强连通分量。BFS 用队列，适合求无权图的最短路径、层次遍历。

复杂度都是 O(V + E)，差别在于空间和访问顺序：DFS 的空间取决于递归深度，最坏 O(V)；BFS 的空间取决于最宽的一层，稠密图可能也接近 O(V)。

## 实现要点

- 邻接表比邻接矩阵省空间，稀疏图优先用邻接表。
- 一定要有 visited 数组，否则有环图会死循环。
- 拓扑排序用 DFS 时要记录"三色状态"（未访问/在栈中/已完成），只靠 visited 布尔值判断不出环。
- BFS 求最短路只能用于无权图；带权图要用 Dijkstra 或 Bellman-Ford。

## 常见坑

递归深度过大时 Python 会 RecursionError，改成显式栈；多源 BFS 要把所有源点同时入队，而不是逐个源点跑一遍。
