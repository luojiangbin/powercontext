# 红黑树

## 五条性质

1. 每个节点是红色或黑色。
2. 根节点是黑色。
3. 叶子节点（NIL）视为黑色。
4. 红色节点的两个子节点必须是黑色（不能红红相连）。
5. 从任一节点到其所有叶子的路径上，黑色节点数目相同（黑高一致）。

## 为什么需要它

普通二叉搜索树在有序插入时退化成链表，查找 O(n)。红黑树通过旋转和变色把树高控制在 2log(n+1) 以内，保证查找、插入、删除都是 O(log n)。AVL 树更严格（高度差不超过 1），查询略快但插入删除的旋转次数更多；红黑树在写入频繁的场景更划算，所以被 Java 的 TreeMap、C++ 的 std::map 采用。

## 插入修复的三种情况

新增节点默认染红，如果父节点是黑色则直接结束。若父节点为红：

- 情况一：叔叔节点为红 → 父与叔染黑，祖父染红，把祖父当作新的当前节点继续向上检查。
- 情况二：叔叔为黑且当前节点是右孩子 → 对父节点左旋，转成情况三。
- 情况三：叔叔为黑且当前节点是左孩子 → 父染黑、祖父染红，对祖父右旋。

删除比插入复杂，核心是"被删节点是黑色时黑高被破坏"，需要向兄弟借黑色，分四种情况讨论。

## 常见坑

- 旋转后忘记更新父指针，导致后续回溯访问到旧结构。
- 把 NIL 当成普通节点去染色，破坏性质五。
- 删除时只处理了兄弟为黑的情况，漏掉兄弟为红需要先旋转。
